# design-sync notes

- Tokens-only sync (no component bundle): the app is React Native with no web `dist/`. Components in Design come later
  via a `react-native-web` target or the future `web/` client.
- Rebuild + re-upload: `node .design-sync/build.mjs` (reads mobile/src/lib/theme/{tokens,typography,metrics}.ts and design/),
  then `/design-sync` (project id is pinned in config.json). Output `ds-bundle/` is gitignored.
- No `_ds_sync.json` anchor is written: every re-sync re-uploads everything (cheap, ~30 files).
- Known doc mismatch (not fixed, by request): design/README.md says cover colour is chosen by city name,
  design/tokens.md says by trip id. The conventions header follows tokens.md.
- Not visually verified in a browser yet (`.glass` blur, font loading via relative url() in tokens/fonts.css).
- Reference material in the project: `guidelines/specs/` = digests of specs/SPEC-*.md (problem, goals/non-goals, user stories,
  screen inventory; ACs omitted, generated by build.mjs) and `guidelines/mockups/` = snapshot of the Design canvas
  "Travel Tracker — вариант A" (https://claude.ai/artifact/9Gz2gvzQjkbD9rG2tqiLtu, 16 `.dc.html` artboards).
  The snapshot is a manual copy in `.design-sync/mockups-src/` (gitignored). To refresh: re-read `project/*.dc.html` +
  `project/canvas.json` from the artifact (Artifact `read` with `paths`, `out_dir` = `.design-sync/mockups-src`), then rebuild + upload.
- The mockups violate current rules (emoji flags, font-weight 600, gradients, text glyph icons, hard-coded hex); the mockups README
  in the project says "layout/flow only, not styling". Fix the source mockups when the screens are reworked.
- "Трекер путешествий — проект" (https://claude.ai/artifact/QCrBNoYRR6o4oNeTXJqkh5) is a Claude Docs document, not a mockup:
  read via the Claude Docs connector, not `Artifact read`. Not included in the project.
