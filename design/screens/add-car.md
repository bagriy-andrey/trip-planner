# Форма аренды авто и просмотр брони

Добавление и редактирование одной аренды внутри поездки (S16 создание, S16b правка) и экран
просмотра брони S17 — то, что открывают на стойке проката. Оболочка формы — как в `add-hotel.md`:
модальная шторка, шапка с крестиком (голосом «Отмена») и заголовком «Аренда авто» по центру,
**без** «Готово»; прокручиваемое тело (`space.block` сверху, `space.screenX` по бокам, `space.lg`
между полями); нижняя панель с «Сохранить» (пилюля 52, `accent` / `onAccent`, Bold 15).
«Сохранить и добавить следующий» нет. Контракт — `specs/SPEC-07-car-rental.md`; макет —
Claude Design, `templates/car-rental` (hi-fi, только токены темы).

Поле ввода: высота 48, `radius.field`, фон `surface`, рамка 1 `surfaceBorder`, отступ по X
`space.lg`; подпись над полем — Bold 12 `textSecondary`, зазор `space.sm`. Заголовки групп — `h2`.

## Шторка «Даты аренды»

- Поверх формы: подложка `scrim` (fade), панель снизу (slide) токенами `motion.sheetEnter` (280ms) /
  `sheetExit` (200ms), easing `cubic-bezier(.2,.8,.2,1)`; «Уменьшить движение» — без анимации. Тот же
  механизм, что у шторки валюты отеля.
- Панель: фон `bg`, рамка `surfaceBorder` без нижней, радиус `radius.sheet` сверху; ручка 36×4 `divider`;
  заголовок «Даты аренды» (`h2`) и подсказка (13, `textSecondary`): «Выберите день получения» →
  «Теперь день возврата» → выбранный диапазон.
- Навигация месяца: стрелки 44×44, по центру «Август 2026» (Bold 15). Сетка 7 колонок, неделя с
  понедельника, дни недели 12 `textTertiary`. День: ячейка 44, кружок 40, моно 13. Начало и конец —
  `accent` / `onAccent`; между ними полоса `surfaceStrong` (скругление 22 у краёв).
- Логика: первый тап — начало (конец сбрасывается), второй — конец; тап раньше начала переносит начало;
  тот же день — аренда на один день.
- «Готово» (пилюля 52) активна только с обеими датами, записывает диапазон и закрывает. Тап по
  подложке или свайп вниз — закрыть без изменений. Открывается на месяце начала.
- Предзаполнение — даты поездки (начало не раньше сегодня). При создании дни раньше сегодня отключены и
  приглушены, листать раньше текущего месяца нельзя; при правке аренды из прошлого нижняя граница —
  её получение.
- Формат поля: «19 – 27 авг 2026»; разные месяцы «30 авг – 2 сент 2026»; разные годы
  «30 дек 2026 – 3 янв 2027». Месяцы: янв фев мар апр мая июн июл авг сент окт нояб дек.

## Поведение

- Предзаполнение при создании: даты поездки; времена пусты; «Возврат там же» включён; валюта — домашняя
  валюта профиля (только умолчание для новой записи; при правке — валюта аренды).
- Время получения и возврата — как время отеля: пустое поле — кнопка, первый тап открывает выбор
  (iOS — нижняя шторка с колесом, Готово/Отмена; Android — системный диалог); значение пишется только
  по подтверждению. Оба обязательны, «×» нет.
- Возврат (дата + время) не раньше и не равен получению — иначе ошибка под «Время возврата» (`danger`),
  сохранение заблокировано. Пустые обязательные поля — ошибки под полями, все сразу.
- Предупреждение (единственная проверка нестыковок в первой фазе): если возврат авто позже вылета
  обратного рейса поездки — плашка `warnBg` / `warnBorder` под временами, «успеть не получится».
  Не блокирует сохранение; считает `shared/` (`carReturnAfterFlight`), рейс — с самым поздним вылетом;
  нет рейсов — нет плашки.
- Ссылка на карты, стоимость и валюта, отброс лишних символов — как в `add-hotel.md`.
- Тап вне поля ввода снимает фокус и прячет клавиатуру.
- Правка (S16b): значения показываются как сохранены (местные, без пересчёта зон); внизу тела —
  текстовая кнопка «Удалить аренду» (`danger`, Bold 15, без заливки) → подтверждение поверх экрана
  (не системный `Alert`, паттерн `add-flight.md`). Если в «Ещё» есть заполненное поле, блок раскрыт.
- Закрытие с несохранёнными правками — «Закрыть без сохранения?» снизу поверх экрана.
- Ошибка сохранения/удаления — в форме, введённое остаётся; кнопка заблокирована на время запроса.
- Неизвестный, чужой или не-UUID `carId` — состояние «Аренда не найдена» (на S16b и S17).

## Карточка на S7, блок «Аренда авто»

Стеклянная карточка (`surface` + blur + рамка), `radius.card`, отступ 16, gap 12:

1. «Компания» (Bold 15) + шеврон 16 `textTertiary`. Без компании — «Аренда авто».
2. Сетка 2 колонки: подпись (caption `textSecondary`) «Получение» / «Возврат»; значение — моно 13
   «19 авг, 11:00» и под ним место (caption `textSecondary`). У возврата при «там же» — «Там же».
3. Разделитель `divider`, затем «Бронь» (caption) + номер моно 13.

Сортировка по получению. Тап → S17. Пустое состояние — «Добавить автомобиль» (как сейчас).
Адрес, телефон, условия, оплата и заметки в карточке не показываются.

## Просмотр брони (S17)

`/trips/[tripId]/cars/[carId]/view`. Шапка: «назад» 44, «Аренда авто» по центру, справа «Изменить»
(Bold 15, `accent`, ≥44pt) → S16b. Тело: gap `space.gap`, карточки стекла; пустые строки и карточки
не показываются:

1. **Главная** (`glass--strong`): компания (ExtraBold 19; без неё — «Аренда авто»), класс (13
   `textSecondary`); «Номер брони» caption + номер моно 19; справа пилюля «Копировать» (иконка `copy` 16)
   → «Скопировано» на 1,5 с.
2. **Цепочка**: узел 8 `accent` (залит) — «Получение», «Ср, 19 авг · 11:00» моно 15, место 13; узел 8
   контурный — «Возврат», то же (при «там же» — «Там же»).
3. **Офис**: адрес (15); две пилюли 44 в ряд: «Маршрут» (`accent`, иконка `navigation`) — открывает
   ссылку на карты системно (повторная проверка `parseMapsUrl`); «Позвонить» (`surface` + рамка, иконка
   `phone`) — `tel:`. Нет ссылки / телефона — соответствующая кнопка скрыта.
4. **Условия**: сетка подпись / значение (caption / Bold 13): Страховка, Топливо, Оплата
   («383,35 EUR · оплачено»), Доп. водитель, Залог.
5. **Заметки**: если заполнены.

## Иконки (Feather)

`x`, `chevron-left`, `chevron-right`, `chevron-down`, `calendar`, `map-pin`, `navigation`, `phone`,
`copy`, `plus`; `car` (Ionicons) — пустое состояние блока.

## Чего здесь нет

Поиска прокатных компаний, цен, сравнения, часов работы офиса, поля «Водитель», импорта из ваучера,
превью карты. Всё вводится руками.

## Решения, которые ещё надо принять

- Тап по карточке: у авто — на просмотр, у отеля — сразу в форму. Выбрать единообразно (SPEC-07, Follow-ups).
- Календарь: у авто — в шторке, у отеля — встроенный под полем. Стоит унифицировать.
