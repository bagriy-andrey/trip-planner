# Форма аренды авто

Добавление и редактирование одной аренды внутри поездки. Оболочка экрана —
как в `add-flight.md`.

## Поля

| Поле | Тип | Замечание |
| --- | --- | --- |
| Компания | текст | обязательное |
| Адрес получения | текст | многострочный |
| Дата и время получения | дата + время | два поля в ряд, значения моно |
| Адрес возврата | текст | по умолчанию совпадает с получением |
| Возврат в другом месте | переключатель | включён — показывает отдельный адрес возврата |
| Дата и время возврата | дата + время | два поля в ряд, значения моно |
| Модель или класс | текст | необязательное |
| Водитель | текст | имя как в правах |
| Стоимость | число + валюта | валюта на уровне записи |
| Номер брони | текст | моно |
| Условия | текст | франшиза, лимит пробега, топливо — свободная заметка |

## Поведение

- Дата получения предзаполняется датой начала поездки, возврата — окончания.
- Возврат раньше получения — ошибка под полем цветом `danger`,
  сохранение блокируется.
- Если время возврата авто позже времени вылета обратного рейса, показать
  предупреждение на фоне `warnBg`: успеть не получится. Это единственная
  проверка нестыковок в первой фазе, и она дешёвая — обе даты уже введены.
