# Экран «Поездки» (главный)

Список активных и будущих поездок. Первый таб, экран по умолчанию после входа.

## Структура сверху вниз

1. Шапка: заголовок «Поездки» (`h1`, ExtraBold) слева, круглый аватар 38
   с инициалом справа. Тап по аватару → Профиль.
2. Вертикальный список карточек поездок, отступ между ними `spacing.gap`.
3. Плавающая кнопка «+»: круг `layout.fabSize`, фон `accent`, иконка плюса
   цветом `onAccent`, прижата к правому краю, над таб-баром. Тап → Новая поездка.
4. Таб-бар (см. `navigation.md`), активен первый раздел.

## Карточка поездки

Высота `layout.coverHeight`, радиус `radius.cover`, содержимое обрезается.

- Подложка: плотный цвет из `coverColors` по названию города, по центру
  контурная иконка метки 120×120 на 16% прозрачности.
- Снизу стеклянная панель `surfaceStrong` с блюром и верхней границей:
  - строка 1: название города (`cardTitle`, ExtraBold) слева, чип статуса справа;
  - строка 2: даты моношрифтом (`small`, `textSecondary`).
- Тап по карточке → Детали поездки.

### Чип статуса

- Ближайшая поездка: фон `accent`, текст `onAccent`, содержимое «через N дней».
- Остальные будущие: фон `divider`, текст `textSecondary`.
- Без дат: текст «план», даты заменяются на «дата не выбрана» цветом `textTertiary`.

## Состояния

- Пусто: короткий текст, что поездок пока нет, и подсказка на кнопку «+».
  Не рисовать большую иллюстрацию.
- Загрузка: скелетоны карточек той же высоты, без спиннера по центру.
- Поездка уходит из списка автоматически, когда прошла дата окончания.

## Данные

Список поездок текущего пользователя со статусом не «архив», отсортированный
по дате начала: ближайшая сверху, поездки без дат в конце.
