# Экран «Поездки» (главный)

Список активных и будущих поездок. Первый таб, экран по умолчанию после входа.

## Структура сверху вниз

1. Шапка: заголовок «Поездки» (`h1`, ExtraBold) слева, круглый аватар 38
   с инициалом справа. Тап по аватару → Профиль.
2. Вертикальный список карточек поездок, отступ между ними `spacing.gap`.
3. Плавающая кнопка «+»: круг `layout.fabSize`, фон `accent`, иконка плюса
   цветом `onAccent`, прижата к правому краю, над таб-баром. Тап → Новая поездка.
4. Таб-бар (см. `navigation.md`), активен первый раздел.

## Карточка поездки

Высота `layout.coverHeight`, радиус `radius.cover`, содержимое обрезается.

- Подложка: плотный цвет из `coverColors` по идентификатору поездки (не по названию
  места: переименование, смена названия и смена языка цвет не меняют), по центру
  контурная иконка метки 120×120 на 16% прозрачности.
- Снизу стеклянная панель `surfaceStrong` с блюром и верхней границей:
  - строка 1: название города (`cardTitle`, ExtraBold) слева, чип статуса справа;
  - строка 2: даты моношрифтом (`small`, `textSecondary`).
- Тап по карточке → Детали поездки.

### Чип статуса

- Ближайшая поездка — **ровно одна** в списке (у кого раньше начало; при равных
  датах — созданная раньше): фон `accent`, текст `onAccent`, содержимое
  «через N дней». Если поездка уже идёт (начало сегодня или раньше), вместо
  отрицательного числа — «сегодня».
- Остальные будущие: фон `divider`, текст `textSecondary`. Акцентного чипа
  у них нет, даже если у нескольких поездок одинаковая дата начала.
- Без дат: текст «план», даты заменяются на «дата не выбрана» цветом `textTertiary`.

## Состояния

- Пусто: заголовок «Поездок пока нет» и подсказка «Добавьте первую кнопкой справа
  внизу» (на кнопку «+»). Не рисовать большую иллюстрацию.
- Загрузка (первая): скелетоны карточек той же высоты (`layout.coverHeight`,
  `radius.cover`, фон `divider`), без спиннера по центру и без мерцания.
- Ошибка загрузки: «Не удалось загрузить поездки», под ним причина (нет сети,
  сервер долго не отвечает, нет доступа, иное) и кнопка «Повторить», которая
  запрашивает список заново. Это отдельное состояние: пустой список
  «Поездок пока нет» при ошибке не показывается. Если данные уже на экране,
  а обновление не удалось, список остаётся как есть.
- Поездка уходит из списка автоматически, когда прошла дата окончания
  (перерасчёт по текущей дате, без повторного запроса), и когда её отправили
  в архив; она появляется в «Истории».

## Данные

Список поездок текущего пользователя со статусом не «архив», отсортированный
по дате начала: ближайшая сверху, поездки без дат в конце.
