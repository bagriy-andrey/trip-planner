# Навигация

Нижний таб-бар с тремя разделами: Поездки, История, Профиль. Детали поездки
и формы открываются поверх, без таб-бара. Создание поездки — модальная шторка.

Имена маршрутов зафиксированы по существующему коду.

## Переходы

- Онбординг → Вход → (Регистрация ↔ Вход) → Поездки
- Онбординг показывается один раз. После первого прохождения корневой
  маршрут ведёт в Поездки, а выход из профиля — на Вход, а не на онбординг.
- Поездки: карточка → Детали поездки; «+» → Новая поездка
- Новая поездка: «Создать» → Детали созданной поездки, без подсказок;
  «Отмена» → назад в список
- Детали поездки: «+» у модуля → форма этого модуля; карточка записи →
  та же форма в режиме редактирования с подставленным id; блок документов →
  Документы
- История: карточка → Детали поездки, тот же экран, без режима «только чтение»

## Формы редактирования

Маршрут с id открывает существующую запись, а не пустую форму. Если id
игнорируется и форма всегда пустая — это баг, а не заглушка.
