# Форма рейса

Добавление и редактирование одного рейса внутри поездки.
Оболочка экрана общая для всех форм модулей; поля отеля и авто —
в `add-hotel.md` и `add-car.md`.

## Структура

1. Шапка: «Отмена» слева (`textSecondary`), название модуля по центру (Bold),
   «Готово» справа цветом `accent`. Снизу разделитель.
2. Прокручиваемое тело формы.
3. Нижняя панель с кнопкой «Сохранить» на фоне `accent`.

## Поля

| Поле | Тип | Замечание |
| --- | --- | --- |
| Откуда | текст с подсказками | из офлайн-справочника аэропортов |
| Куда | текст с подсказками | то же |
| Дата вылета | дата | значение моношрифтом |
| Время | время | значение моношрифтом |
| Багаж включён | переключатель | пилюля 44×24, включённая — на фоне `accent` |
| Пассажиры | счётчик | круглые кнопки минус и плюс, минимум 1 |
| Место | текст | моношрифтом |
| Номер билета | текст | моношрифтом |

Подпись поля — `caption`, Bold, цвет `textSecondary`, отступ 6 под ней.
Поле — фон `surface`, граница `surfaceBorder`, радиус `radius.field`.
Два коротких поля ставятся в ряд через `spacing.gap`.

## Поведение

- Переключатели и счётчики работают локально, сохранение — по кнопке.
- Предзаполнение: город назначения берётся из поездки, дата вылета — из даты
  начала поездки, обратный рейс меняет города местами.
- Закрытие без сохранения спрашивает подтверждение, только если что-то
  изменено.

## На будущее

Автозаполнение по номеру рейса: человек вводит номер и дату, поля
заполняются сами. Вынесено в отдельную задачу, в текущей форме не реализуется.
