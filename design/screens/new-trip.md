# Экран «Новая поездка» / «Изменить поездку»

Модальная шторка поверх списка поездок. Открывается кнопкой «+».
Единственное обязательное поле — «Куда».

Одна и та же шторка работает в двух режимах: **создание** (маршрут `trips/new`)
и **правка** (маршрут `trips/[tripId]/edit`, пункт «Изменить» в меню «…» деталей).
Форма и правила проверки одни и те же, различаются заголовок, кнопка, начальные
значения и то, куда ведёт успех. См. раздел «Режим правки».

## Структура

Шторка занимает экран ниже 104pt сверху, радиус `radius.sheet` сверху,
под ней затемнение `scrim`. Сверху по центру — серая «ручка» 36×4.

1. Шапка: «Отмена» слева (`textSecondary`), «Новая поездка» (в режиме правки —
   «Изменить поездку») по центру (Bold), справа пустое место той же ширины
   для симметрии. Кнопки «Готово» в шапке нет ни в одном режиме: сохраняет
   нижняя кнопка. Снизу разделитель.
2. Поле «Куда»: подпись, затем строка с иконкой метки, текстовым инпутом
   и крестиком очистки, когда что-то введено. Граница поля становится
   акцентной, когда место выбрано из подсказок.
3. Выпадающий список подсказок под полем, когда есть совпадения.
4. Поле «Название поездки» с подписью и пояснением, что подставится город.
5. Блок «Даты»: одно поле с диапазоном («Выберите даты» / «5–9 окт. 2026»), ниже чекбокс
   «Пока без дат», ниже пояснение про черновик.
6. Нижняя панель с кнопкой «Создать поездку» (в режиме правки — «Сохранить»).

## Подсказки мест

Источник — встроенный офлайн-справочник. В нём и города, и страны: человек
может ехать «в Португалию», а не только «в Порту».

Строка подсказки: название (Bold) сверху, под ним тип и уточнение
(«Город · Польша», «Страна · Европа») цветом `textTertiary`, справа код
аэропорта моношрифтом — только для городов, у стран пусто.

Фильтр по началу названия. Показывать не больше четырёх.

Если совпадений нет — подсказки не показываются, вместо них строка
«Ничего не нашли — оставим как есть, это тоже подойдёт». Поле принимает
любой текст: справочник помогает, но не ограничивает.

Выбор из справочника даёт стране принадлежность, таймзону и код аэропорта —
они нужны дальше для корректного времени и записи.

### Справочное место и свободный текст

- Место считается «выбранным из справочника» только после нажатия на строку
  подсказки: граница поля становится акцентной.
- Любое редактирование текста сразу отменяет выбор: место становится свободным
  текстом, граница снова обычная, страна, таймзона и код аэропорта не сохраняются.
  Это верно и для текста, который случайно совпал с названием из справочника, —
  выбирает только нажатие на подсказку.
- Подсказки открываются, когда человек печатает, а не когда поле заполнено
  извне: предзаполненное значение в режиме правки список не открывает.
- Поездка со справочным местом в режиме правки открывается с уже выбранным
  местом (акцентная граница, название на текущем языке интерфейса). Если
  сохранённый идентификатор справочник больше не знает, место открывается
  как свободный текст.

## Поведение

- Автофокус на поле «Куда» при открытии в режиме создания, клавиатура сразу
  открыта. В режиме правки автофокуса нет.
- Название необязательно. Пустое — подставляется выбранное место.
- Даты необязательны. Один тап по полю раскрывает под ним календарь-диапазон
  (месяц, стрелки «назад/вперёд»): первый тап по дню — начало, второй — конец.
  Второй тап по более раннему дню переносит начало, тап по тому же дню даёт
  поездку на один день. Пока конец не выбран, в форму ничего не записывается
  (никакой «сегодняшней» даты по умолчанию); после второго тапа календарь
  сворачивается, а в поле показан диапазон. Календарь открывается на месяце
  начала или на текущем.
- Чекбокс «Пока без дат» скрывает кнопки выбора дат и показывает пояснение про
  черновик. Введённые даты не теряются (снимешь галочку — вернутся), но
  при сохранении не отправляются.
- Ошибки дат показываются один раз под блоком «Даты»: «укажите обе даты или
  „Пока без дат“», «конец раньше начала», «дольше 365 дней».
- Кнопка «Создать поездку» неактивна, пока поле «Куда» пустое:
  фон `divider`, текст `textTertiary`. Остальные проверки идут по нажатию,
  рядом с полем; неверный ввод не уходит в сеть.
- Пока запрос идёт, кнопка занята (спиннер) и второе нажатие ничего не
  отправляет. При ошибке сети введённое остаётся, сообщение — над кнопкой,
  повтор — той же кнопкой.
- После создания — сразу Детали поездки (шторка заменяется, а не закрывается:
  жест «назад» не вернёт форму), без подсказок и без туров.

## Режим правки

Открывается из меню «…» деталей: заголовок «Изменить поездку», кнопка
«Сохранить», «Готово» в шапке нет.

- Поля предзаполнены сохранёнными значениями: место (название на текущем языке
  интерфейса), название поездки, даты.
- У поездки без дат чекбокс «Пока без дат» уже отмечен, кнопки дат скрыты.
- Пока поездка загружается, вместо формы — индикатор. Если поездки нет
  (удалена, чужая, битый идентификатор) — состояние «Поездка не найдена»
  с кнопкой возврата, форма не показывается. Ошибка загрузки — сообщение
  и «Повторить».
- «Сохранить» обновляет поездку и возвращает на Детали (шторка закрывается назад).
  «Отмена» закрывает без сохранения.

## Чего здесь нет

Статуса поездки отдельным переключателем: поездка без дат сохраняется
как черновик, это выводится из дат. Валюты. Создания по номеру рейса.
Выбора транспорта — он выбирается уже внутри поездки.
