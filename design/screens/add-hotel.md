# Форма отеля

Добавление и редактирование одного отеля внутри поездки (S14 создание,
S14b правка). Оболочка экрана — как в `add-flight.md`: шапка только с заголовком
«Отель» (без крестика и без «Готово»); прокручиваемое тело, в конце
которого одна за другой кнопки «Сохранить», «Отмена» (при правках — с
подтверждением) и, при правке, «Удалить отель» (та же пилюля, рамка и текст
`danger`); фиксированной панели нет. «Сохранить и добавить следующий»
нет. Контракт — `specs/SPEC-05-hotels.md`.

## Поля (порядок сверху вниз)

| Поле | Тип | Замечание |
| --- | --- | --- |
| Название | текст | обязательное, до 120 символов |
| Город | текст с подсказками | только выбор из справочника мест, обязательное; предзаполняется городом поездки; из него берётся таймзона (в форме не показывается) |
| Адрес | текст | многострочный, необязательный, до 300 |
| Ссылка на карты | ссылка | только Google Maps (`https`, белый список хостов); необязательная |
| Даты | диапазон дат | ОДНО поле «с — по» (значение моно), тап открывает нижнюю шторку «Даты проживания» с календарём (как «Даты аренды»): «с», затем «по», диапазон подсвечен, применяется по «Готово»; выезд в тот же день допустим; обе даты обязательны; при создании дни раньше сегодня отключены и приглушены, листать раньше текущего месяца нельзя (при правке отеля из прошлого нижняя граница — его заезд); начало поездки из прошлого при префилле = сегодня |
| Время заезда | время | необязательное, стоит в одном ряду с «Временем выезда» (как «Время получения»/«Время возврата» у аренды), отдельное поле, без значения по умолчанию; пустое поле — обычная кнопка с иконкой часов; ПЕРВЫЙ тап сразу открывает шторку выбора времени (iOS: нижняя шторка с нативным колесом, Готово/Отмена; Android: системный диалог), колесо открывается на 15:00; поле остаётся пустым, пока время не подтверждено; отмена/касание подложки — пусто; заполненное поле тоже открывает шторку на текущем значении; «×» очищает |
| Время выезда | время | необязательное, отдельное поле, без значения по умолчанию; пустое поле — кнопка, первый тап открывает ту же шторку на 11:00 (значение ставится только по «Готово»); «×» очищает; ошибка «Выезд должен быть позже заезда» — под этим полем |
| Ночей | вычисляется | не поле ввода, строка «N ночей — считается из дат» под датами |
| Гостей | степпер | 1…9, по умолчанию 1; не моно |
| Парковка | сегмент-контроль | Нет / Бесплатно / Платно |
| Завтраки | сегмент-контроль | Все дни / Частично / Нет |
| Дней с завтраком | степпер | только при «Частично»; по умолчанию 1, диапазон 1…max(1, ночей − 1), без известных ночей 1…30 |
| Стоимость | число + валюта | сумма — только цифры и один десятичный разделитель (`.` или `,`), до 2 знаков после него и до `MONEY_MAX_INTEGER_DIGITS` целых (фильтр при вводе и вставке; валидность решает `parseMoneyAmount`); валюта — выпадающий список: кнопка-поле с кодом (пусто: приглушённый плейсхолдер `EUR`, не значение; пока сумма заполнена, подпись «Валюта (обязательно)») открывает нижнюю шторку (плавно: подложка гаснет/появляется, панель выезжает снизу и уезжает при закрытии, `motion.sheetEnter/sheetExit`; при «Уменьшить движение» без анимации) с поиском по коду и названию и полным списком, «Не выбрана» снимает; валюта на уровне записи; при создании предзаполняется домашней валютой профиля (при правке — валютой отеля); валюта без суммы не ошибка (сохраняется без стоимости); сумма без валюты — ошибка под полем после ухода из суммы и при сохранении; отброшенный символ в поле суммы не виден ни на миг (нативный текст прозрачный, принятый рисуется поверх) |
| Номер брони | текст | моно, до 32 |
| Удобства и требования | текст | свободная заметка, до 1000 |

## Поведение

- Тап вне поля ввода (подпись, пустое место, кнопка, календарь, шторка) снимает фокус с активного поля и прячет клавиатуру; тап по самому полю фокус сохраняет (`DismissKeyboardView`).

- Диапазон дат предзаполняется датами поездки (при правке — датами отеля); времена пустые,
  пока не выбраны. Один тап по пустому полю времени открывает пикер, у заполненного справа
  крестик «Очистить».
- Число ночей считает `shared/` (`nightsBetweenDates`, календарные даты), клиент
  не пересчитывает; строка скрыта, пока нет обеих дат или ночей 0. Максимум 365.
- При смене дат «Дней с завтраком» приводится к границе нового диапазона.
- Пустые даты — ошибки под полем «Даты»; в один день с обоими временами выезд не позже заезда —
  ошибка под полем «Время выезда» цветом `danger`, сохранение заблокировано. Все ошибки показываются сразу.
- Если поездка без дат, даты не предзаполняются, ночи не показываются.
  Если города поездки нет в справочнике, «Город» пуст.
- Ссылка на карты: когда ссылки нет — поле вставки; ссылка принимается
  при уходе из поля или при сохранении, а не на каждый символ. Когда добавлена —
  строка «Ссылка добавлена / Google Maps», кнопка «Открыть» (повторная проверка,
  затем системное открытие; ошибка показывается в форме) и «×» «Убрать ссылку».
  Сетевых запросов ради ссылки нет.
- Правка (S14b): даты и времена показываются как сохранены (местные для отеля, без пересчёта зон);
  в конце формы кнопка «Удалить отель» с подтверждением поверх экрана (не системный
  `Alert`); неизвестный, чужой или не-UUID id — состояние «Отель не найден».
- Закрытие с несохранёнными правками — «Закрыть без сохранения?» снизу поверх экрана.
- Ошибка сохранения/удаления показывается в форме, введённое остаётся; кнопка
  заблокирована на время запроса.

## Известное расхождение

На iOS нативный компактный пикер даты/времени не позволяет задать моно-шрифт
значения, поэтому выбранное время в самом пикере не моно (пробел в AC-14
для iOS); в остальных местах формы значения моно.

## Чего здесь нет

Поиска отелей, подтягивания данных из Booking, превью карты и раскрытия
коротких ссылок. Адрес — просто текст. E2E-флоу «добавить отель» ещё не написан.
