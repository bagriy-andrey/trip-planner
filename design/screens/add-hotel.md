# Форма отеля

Добавление и редактирование одного отеля внутри поездки. Оболочка экрана —
как в `add-flight.md`: шапка «Отмена / название / Готово», прокручиваемое
тело, нижняя панель с кнопкой «Сохранить».

## Поля

| Поле | Тип | Замечание |
| --- | --- | --- |
| Название | текст | обязательное |
| Город | текст с подсказками | предзаполняется из поездки |
| Адрес | текст | многострочный, необязательный |
| Check-in | дата и время | два поля в ряд, значения моно |
| Check-out | дата и время | два поля в ряд, значения моно |
| Ночей | вычисляется | не поле ввода, строка под датами |
| Завтраки | выбор | «включены все дни» / «включены частично» / «не включены» |
| Дней с завтраком | счётчик | показывается только при «включены частично» |
| Стоимость | число + валюта | валюта на уровне записи |
| Номер брони | текст | моно |
| Удобства и требования | текст | свободная заметка |

## Поведение

- Check-in предзаполняется датой начала поездки, check-out — датой окончания.
  Число ночей считается само и обновляется при смене дат.
- Check-out раньше check-in — ошибка под полем цветом `danger`,
  сохранение блокируется.
- Если поездка без дат, даты не предзаполняются и считать ночи нечего.
