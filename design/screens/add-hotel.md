# Форма отеля

Добавление и редактирование одного отеля внутри поездки (S14 создание,
S14b правка). Оболочка экрана — как в `add-flight.md`: шапка с крестиком
(голосом «Отмена»), заголовком «Отель» и **без** «Готово»; прокручиваемое
тело; нижняя панель с кнопкой «Сохранить». «Сохранить и добавить следующий»
нет. Контракт — `specs/SPEC-05-hotels.md`.

## Поля (порядок сверху вниз)

| Поле | Тип | Замечание |
| --- | --- | --- |
| Название | текст | обязательное, до 120 символов |
| Город | текст с подсказками | только выбор из справочника мест, обязательное; предзаполняется городом поездки; из него берётся таймзона (в форме не показывается) |
| Адрес | текст | многострочный, необязательный, до 300 |
| Ссылка на карты | ссылка | только Google Maps (`https`, белый список хостов); необязательная |
| Заезд | дата и время | два поля в ряд, значения моно; время открывается на 15:00 |
| Выезд | дата и время | два поля в ряд, значения моно; время открывается на 11:00 |
| Ночей | вычисляется | не поле ввода, строка «N ночей — считается из дат» под датами |
| Гостей | степпер | 1…9, по умолчанию 1; не моно |
| Парковка | сегмент-контроль | Нет / Бесплатно / Платно |
| Завтраки | сегмент-контроль | Все дни / Частично / Нет |
| Дней с завтраком | степпер | только при «Частично»; по умолчанию 1, диапазон 1…max(1, ночей − 1), без известных ночей 1…30 |
| Стоимость | число + валюта | валюта на уровне записи, не предзаполняется; сумма и валюта — оба или ни одного |
| Номер брони | текст | моно, до 32 |
| Удобства и требования | текст | свободная заметка, до 1000 |

## Поведение

- Заезд предзаполняется датой начала поездки, выезд — датой окончания;
  время пустое, пока не выбрано. Один тап по пустому полю открывает пикер,
  у заполненного справа крестик «Очистить». Дата выезда не раньше даты заезда.
- Число ночей считает `shared/` (календарные даты в таймзоне отеля), клиент
  не пересчитывает; строка скрыта, пока нет обеих дат или ночей 0. Максимум 365.
- При смене дат «Дней с завтраком» приводится к границе нового диапазона.
- Выезд не позже заезда — ошибка под полем «Выезд» цветом `danger`,
  сохранение заблокировано. Все ошибки формы показываются сразу.
- Если поездка без дат, даты не предзаполняются, ночи не показываются.
  Если города поездки нет в справочнике, «Город» пуст.
- Ссылка на карты: когда ссылки нет — поле вставки; ссылка принимается
  при уходе из поля или при сохранении, а не на каждый символ. Когда добавлена —
  строка «Ссылка добавлена / Google Maps», кнопка «Открыть» (повторная проверка,
  затем системное открытие; ошибка показывается в форме) и «×» «Убрать ссылку».
  Сетевых запросов ради ссылки нет.
- Правка (S14b): сохранённые значения показываются в таймзоне отеля, не устройства;
  в шапке/теле есть «Удалить отель» с подтверждением поверх экрана (не системный
  `Alert`); неизвестный, чужой или не-UUID id — состояние «Отель не найден».
- Закрытие с несохранёнными правками — «Закрыть без сохранения?» снизу поверх экрана.
- Ошибка сохранения/удаления показывается в форме, введённое остаётся; кнопка
  заблокирована на время запроса.

## Известное расхождение

На iOS нативный компактный пикер даты/времени не позволяет задать моно-шрифт
значения, поэтому выбранные дата и время в самом пикере не моно (пробел в AC-14
для iOS); в остальных местах формы значения моно.

## Чего здесь нет

Поиска отелей, подтягивания данных из Booking, превью карты и раскрытия
коротких ссылок. Адрес — просто текст. E2E-флоу «добавить отель» ещё не написан.
