# Выбор из списка (общий компонент)

Модальная шторка с поиском для выбора одного значения из длинного списка.
Один компонент на четыре места: гражданство, страна проживания, город,
домашний аэропорт, валюта. Позже — выбор аэропортов в форме рейса.

Нативный селект здесь не годится: списки длинные, без поиска по ним
не пройти, а вид системного селекта не подчиняется теме.

## Структура

Шторка ниже 104pt от верха, радиус `radius.sheet` сверху, под ней `scrim`.
Сверху «ручка» 36×4.

1. Шапка: «Отмена» слева, название поля по центру, справа пустое место
   той же ширины для симметрии.
2. Строка поиска: иконка лупы, поле ввода, крестик очистки когда есть текст.
   Автофокус при открытии.
3. Список результатов одной карточкой с разделителями между строками.

## Строка списка

Слева знак: флаг страны для стран и городов, ничего для аэропортов и валют.
Дальше название во всю оставшуюся ширину. Справа код моношрифтом —
двухбуквенный для страны, IATA для аэропорта, ISO для валюты.
У выбранного значения справа галочка цветом `accent`, а фон строки `surface`.

## Поиск

Фильтр по началу названия, плюс точное совпадение по коду: «PL» находит
Польшу, «KRK» — Краков. Поиск регистронезависимый.

Пусто — показываются все значения списком. Ничего не найдено — сообщение
«Ничего не нашли» и строка о том, что поле необязательное. Свой текст,
в отличие от поля «Куда» в новой поездке, здесь не принимается: значение
должно быть из справочника, иначе код страны или аэропорта не на что
опереть.

## Про флаги

Флаг рисуется эмодзи. Это сознательное исключение из правила «эмодзи
в интерфейсе запрещены»: флаг здесь — это данные о стране, а не иконка UI,
и эмодзи даёт его нулевым весом и нативным видом на iOS.

Исключение требует оговорки в `AGENTS.md` и запасного варианта: на части
Android эмодзи-флаги не рендерятся, там вместо флага показывается
двухбуквенный код страны моношрифтом.
