# Дизайн-система

Направление: минимализм плюс liquid glass. Полупрозрачные стеклянные панели
поверх цветных обложек, глубокий тёмный фон, один тёплый акцент. Тёмная тема
основная — стекло на ней читается выразительнее, но светлая равноправна.

Значения токенов — в `tokens.md`. Здесь только смысл: зачем что нужно
и как из этого собираются элементы.

## Смысл токенов

| Токен | Для чего |
| --- | --- |
| `bg` | Фон экрана |
| `surface` | Стеклянная панель: карточки, поля ввода |
| `surfaceStrong` | Панель поверх картинки или таб-бар — плотнее, чтобы текст читался |
| `surfaceBorder` | Граница стеклянной панели, всегда в паре с фоном панели |
| `divider` | Разделители строк, неактивные заливки, точки индикатора, фон отключённой кнопки |
| `text` / `textSecondary` / `textTertiary` | Основной, пояснительный, служебный текст |
| `accent` / `onAccent` | Главное действие, активный таб, статус ближайшей поездки |
| `warnBg` / `warnBorder` | Предупреждения вроде истекающей страховки |
| `danger` | Только деструктивные действия: выход, удаление аккаунта |
| `scrim` | Затемнение под модальной шторкой |
| `coverScrim` | Тонкое затемнение обложки под стеклянной панелью |
| `invertedPill` | Кнопка «Продолжить с Apple»: светлая в тёмной теме, тёмная в светлой |

Цвет текста должен быть доступен во всех вариантах: если компонент текста
принимает ограниченный набор, `textTertiary`, `danger` и `invertedPillText` обязаны в нём быть,
иначе часть интерфейса просто нельзя нарисовать.

## Типографика

Manrope для всего: ExtraBold для заголовков экранов и названий городов,
Bold для заголовков секций и кнопок, Medium для основного текста.
SemiBold в проекте не используется.

IBM Plex Mono — только «билетные» данные: коды аэропортов (WAW, KRK), даты
в карточках, номера рейсов, билетов, полисов, места. Это опознавательный знак
продукта, и он работает, только пока применяется строго. Моно в заголовке,
в кнопке или на числе пассажиров — ошибка. Обратное тоже верно: значение
валюты в профиле обязано быть моно.

## Стекло

Стеклянная панель = `BlurView` с интенсивностью `blurIntensity.panel` плюс
фон `surface` (или `surfaceStrong` поверх изображения) плюс граница
`surfaceBorder` толщиной 1. Три части обязательны: без границы панель
теряет края, без блюра это просто прозрачная заливка.

Таб-бар — плавающая пилюля, а не штатный прижатый к низу: отступы
`tabBarInsetX` по бокам и `tabBarBottom` снизу, высота `tabBarHeight`,
радиус `radius.tabBar`, `surfaceStrong` и блюр `blurIntensity.tabBar`.

## Иконки

`@expo/vector-icons`, набор Feather: контурные, одинаковой толщины линии,
без заливок. Feather выбран потому, что не требует нативных модулей
и пересборки dev-client.

Текстовые символы вместо иконок недопустимы. Минимальный набор, который
нужен приложению: метка, самолёт, кровать, автомобиль, шеврон, стрелка назад,
плюс, крестик, галочка, треугольник предупреждения, телефонная трубка,
камера, документ, изображение, часы, чемодан, пользователь, календарь.

## Обложки поездок

Пока фото-API не подключён, обложка — плотный цвет из `coverColors`,
выбранный детерминированно по названию города, с крупной контурной иконкой
метки на 16% прозрачности по центру. Поверх — `coverScrim`, поверх него
снизу стеклянная панель с названием, датами и статусом.

Когда подключится фото по названию города, меняется только подложка;
скрим и стеклянная панель остаются.

Приглушение архивных обложек делается снижением насыщенности подложки
(`coverMuteSaturation`), а не прозрачностью всей карточки: прозрачность
тянет за собой панель и текст и роняет контраст ниже допустимого.

## Чего избегать

Градиентных заливок ради красоты, карточек с цветной полосой слева,
эмодзи в интерфейсе, шрифтов Inter, Roboto и Arial, фальшивых статус-баров,
прозрачности как способа показать отключённое состояние.
