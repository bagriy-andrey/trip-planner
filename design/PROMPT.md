# Промпты для Claude Code — версия 2

Порядок изменился после инвентаризации. Шаг 0 новый: без него всё
остальное бессмысленно, потому что пакет до агента не доходил.

Каждый шаг — отдельная сессия и отдельный коммит с префиксом `design:`.
Не запускать следующий, пока предыдущий не принят.

## Шаг 0. Проводка (руками, две минуты)

Не промпт, а ваши действия:

1. Распаковать пакет поверх репозитория.
2. Удалить `CLAUDE.md` из пакета, если он туда попал в прошлый раз.
3. Вставить содержимое `AGENTS-additions.md` в `AGENTS.md` проекта.
4. `git add design/ AGENTS.md` и закоммитить.

Пока `design/` не в git и правила не в `AGENTS.md`, агент их не видит.

  divider, радиус карточек, блюр, боковой отступ, ширина границы.

  tabInactive, warnBg, warnBorder, danger, scrim, coverScrim, invertedPill,

  «Размеры и отступы».

  и размеры шрифтов по разделу «Типографика».

  системная тема.
